# 继续已有项目

用于已有 PLAN.md 的项目或中断恢复，无需重新描述全部背景。

```text
使用 $goal-driven-engineering 根据 PLAN.md 和仓库证据继续项目，不依赖聊天记忆。
先按 Skill 判断当前模式和恢复要求；若存在 .goal/execution-state.md，修改文件或模式前先按已安装 Skill 内的 references/execution-continuity.md 恢复。
保留缺少 Task Mode 的旧计划所要求的 FULL 语义、活跃 /goal 或明确严格执行的恢复要求、冻结决策和已有修改。复用有效证据，核验未完成工作，在已授权范围内推进第一个未满足的验收条件，简要说明恢复结果。
```
