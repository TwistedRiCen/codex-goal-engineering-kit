# Host capabilities

Read this reference for host-specific invocation or capability gaps. The workflow does not require a specific model or provider. Role responsibilities and acceptance evidence are stable; model selection, reasoning settings, tool permissions, installation paths, and command syntax belong to the host. Codex custom-agent TOML files and /goal are optional platform integrations, not portable prerequisites.

Use native Skill invocation where supported; otherwise ask the host to read this Skill and its relevant references through available file tools or supplied content. Do not assume another host understands $-prefixed invocations, TOML profiles, or /goal. Without /goal, continue through ordinary explicitly authorized tasks from PLAN. FULL, existing journals, and recorded strict or /goal context retain strict recovery even on a different host; if required recovery evidence or tools are unavailable, pause the affected mutation rather than downgrade it.

Check tools before promising execution. Missing file/test capabilities leave affected evidence unverified; missing an independent reviewer leaves its required gate pending. Continue unaffected authorized work. Shared capability and independent-review boundaries remain visible in [SKILL.md](../SKILL.md).
